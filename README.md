# Hollandse Luchten Hackathon

Welcome to the Hollandse Luchten Hackathon repository! This hackathon focuses on data analysis and AI-driven solutions for air quality monitoring using sensor networks.

## Overview

This hackathon is organized around **three distinct challenges**, each focusing on different aspects of air quality data analysis and interpretation. Participants will work with real sensor data from the Hollandse Luchten network to develop innovative solutions.

## Challenges

### [Challenge 1: Colocation and Outlier Detection](./challenge%201/README.md)
Focus on automatically detecting faulty sensors using AI techniques such as statistical analysis, machine learning, and deep learning. Learn how to compare sensor data with regional networks and official reference measurements.

**Key Skills**: Data validation, anomaly detection, machine learning, sensor calibration

### [Challenge 2: Geographic Hotspot Determination with Visual Wind Roses Over Time](./challenge%202/README.md)
Analyze pollution patterns using visual wind roses plotted on maps over time. Develop unsupervised learning approaches to identify geographic hotspots and investigate potential pollution sources.

**Key Skills**: Time-series analysis, geospatial visualization, unsupervised learning, pattern recognition

### [Challenge 3: Generative AI for Data Analysis Support](./challenge%203/README.md)
Create an intelligent agent that assists residents in conducting data analysis. The agent interprets natural language queries and leverages existing data analysis tools to provide answers with full audit trails.

**Key Skills**: Generative AI, natural language processing, tool integration, user interface design

## Data Preparation

A central data dump will be prepared for each challenge, including:
- Pre-processed and calibrated sensor data
- Sensor metadata and quality information
- Reference measurements
- Documentation of available data fields

This is provided to allow participants to focus on analysis and development rather than data extraction and transformation.

3. **Setup your environment** - Follow the instructions in each challenge's README
4. **Begin development** - Start working on your solution
